# RFC 001 — AWS como provedor de nuvem

**Status:** Aceita

AWS foi escolhida pela correspondência direta entre os requisitos e seus serviços:
Lambda para autenticação serverless, EKS para Kubernetes, RDS para PostgreSQL
gerenciado, ECR para imagens e Secrets Manager/KMS para segredos. A infraestrutura
será declarada em Terraform e implantada por GitHub Actions com OIDC.

Alternativas consideradas foram GCP e Azure. Ambas atendem ao desafio, mas exigiriam
Cloud Functions/AKS ou Cloud Run/GKE e não trazem benefício suficiente para compensar
a aderência explícita do termo Lambda no contexto do trabalho.
