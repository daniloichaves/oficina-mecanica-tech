# Postman

Esta pasta contém a collection versionada da API da Oficina Mecânica.

Arquivo principal:

- `oficina-mecanica.postman_collection.json`

Uso recomendado:

1. Importe a collection no Postman.
2. Ajuste a variável `baseUrl` se necessário.
3. Execute os requests na ordem dos folders para criar os dados de apoio.

Observação:

- O Swagger/OpenAPI continua sendo a referência principal do contrato em tempo de execução.
- A collection foi montada para refletir os endpoints expostos em `/api-docs` e facilitar testes manuais.
